## Launcher

- Stable is the default update track; Dev gets changes from master after CI passes.
- Refresh checks the selected track again.
- When an update has downloaded, Play becomes Update & play.
- Content packs installs and removes private .csrpack files.
- Settings and content packs are kept across updates.

## Skate crossover

- Install your private Skate pack, load a CS map and press X.
- Move to push and steer, Space to ollie, Shift to brake; CS guns keep working.
- Content packs > Create Skate pack reads your own prepared Skate Rust Engine install.

Requires your own CS:GO Legacy install from Steam.
