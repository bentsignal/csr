CSGO Rewrite Launcher

Open CSGO Rewrite to check for updates, then press Play.

- Stable is the default release track for friends.
- Dev receives the newest changes from master after CI passes.
- Refresh checks your selected track again.
- Update downloads show progress. Apply an update directly, or choose
  Update & play to install it and start the game.
- Install and remove private .csrpack content from the Content packs tab.
- Your saved settings and content packs survive game updates.

The game still needs your own CS:GO Legacy install from Steam.
