# 2018-era content: research

Research for VISION §7 ("look, sound and feel like 2018 CS:GO") and ROADMAP
Track C. Written 2026-10-11. Nothing here was downloaded into the repo. Local
facts come from this machine's CS:GO Legacy install (app 4465480, 1.38.8.1,
Oct 2023) and Steam folders. Web facts link their source. **Unverified** means
I could not confirm it.

## 0. Key finding: the reference screenshots show Scaleform, not Panorama

VISION calls the target the "2018 launch-era Panorama UI". Both reference
images are the **Scaleform UI** (the Flash UI used from 2012 to Aug 2018), not
Panorama. Evidence, all checked on the local install:

- The case-opening strings "Unlocking Container..."
  (`SFUI_InvUse_Open_Crate_Decoding`) and "Items that might be in this case:"
  (`SFUI_InvUse_Items_InCrate_Header`) appear only in the Scaleform movie
  `csgo/resource/flash/inventorypanel.swf`. No Panorama file in
  `panorama/code.pbin` uses them.
- On the home screen, "View Your Offers" (`SFUI_Store_View_Offers`) and
  "Overwatch F.A.Q." (`SFUI_Overwatch_Faq_Link`) appear only in Scaleform
  movies (`storetile.swf`, `mainmenuoverwatchpanel.swf`).
- The top tab bar (home, PLAY, INVENTORY, WATCH, AWARDS, OPTIONS, power) is
  the Scaleform layout. Panorama moved navigation to a left sidebar
  ([esports.net preview](https://www.esports.net/csgo-panorama-ui-released)).
- The background is `materials/panorama/images/backgrounds/csgo_default.vtf`
  (1024x512 DXT1: blue-grey vignette with the large CT emblem), which still
  ships in the Legacy VPK. I decoded it and it matches the reference.

Timeline: Panorama beta from 2018-06-20
([Valve blog](https://blog.counter-strike.net/2018/06/20482/)). Panorama
became the default on 2018-08-01/02, with Scaleform still available through a
launch option
([patch notes mirror](https://counterstrike.fandom.com/wiki/Counter-Strike:_Global_Offensive_patches/August_2,_2018)).
The 2018-08-29 update dropped Scaleform and the `-legacyscaleformui` option
([patch page](https://counterstrike.fandom.com/wiki/Counter-Strike:_Global_Offensive_patches/August_29,_2018),
[MP1st](https://mp1st.com/?p=98833)). The home reference shows the 2018-08-01
"A New Horizon" post, so it was captured in August 2018 with Scaleform forced
on.

**The owner should confirm the target:** Scaleform as in the screenshots
(what VISION's checklist describes), or real 2018 Panorama. The rest of this
document covers both, but recommends Scaleform because the references and
checklist describe it.

Good news for Scaleform: **the Legacy install still ships the Scaleform UI
movies.** `csgo/resource/flash/` holds 117 files: `mainmenu.swf`,
`mainmenublogpanel.swf`, `mainmenunewspanel.swf`, `mainmenuoverwatchpanel.swf`,
`friendslisterpanel.swf`, `playerprofilepanel.swf`, `storetile.swf`,
`inventorypanel.swf` (case opening), `sharedlib.swf`, `iconlib.swf`,
`fontlib*.swf`, `scoreboard.swf`, `buy-menu.swf`, the HUD movies, and more.
They are zlib-compressed SWF (`CWS`, SWF v8/9, ActionScript 2). The engine
that played them (`scaleformui.dll`) is gone, but the content is there.
`iconlib.swf` contains `mp5sd` (added 2018-08-15), so the set looks like the
final, August 2018 Scaleform state. That makes them the best possible
runtime source (exact date unverified).

`<Map> [Compatibility Version 1.xx.x.x]`, and the version is the last game

### App 730 vs 4465480 and where files land

- Local `C:\Program Files (x86)\Steam\steamapps\workshop\content\` has
  folders for `730` (63 items) and other games. **There is no `4465480`
  folder.** CS:GO Legacy has no Workshop of its own, and its community server
  browser is reported broken because the game expects app 730
  ([VDC](https://developer.valvesoftware.com/wiki/Counter-Strike:_Global_Offensive),
  [GamingOnLinux](https://www.gamingonlinux.com/2026/03/counter-strike-global-offensive-reappears-on-steam-as-a-standalone-download/page=1/)).
- Old CS:GO items land at
  `steamapps\workshop\content\730\<id>\<ugchandle>_legacy.bin`. Each `.bin`
  is a **ZIP containing one `.bsp`** (verified on all 59 local `.bin` files,
  e.g. `819353092\103978299284200195_legacy.bin` holds `de_nuke_old.bsp`).
  CS2 items land as `<id>.vpk` or `<id>_dir.vpk` with `publish_data.txt`. The
  index is `steamapps\workshop\appworkshop_730.acf` (`WorkshopItemsInstalled`
  with `size`, `timeupdated`, `ugchandle`).
- **Subscribing without running the game:** Steam downloads subscribed items
  for installed apps in the background, and this machine keeps the CS:GO-era
  items current under 730 (CS2) even though they are marked "incompatible
  with Counter-Strike 2". Whether a *new* subscription to an incompatible item
  still downloads is **unverified**. The pages may hide the Subscribe button.
- **Direct download without Steam (verified):** the keyless
  `POST https://api.steampowered.com/ISteamRemoteStorage/GetPublishedFileDetails/v1/`
  returns a `file_url` on `cdn.steamusercontent.com/ugc/...` for these items.
  A HEAD request returned `200` with the expected size and no auth (tested on
  1773333823 and on the removed 819353092). This is how the launcher could
  fetch Valve's map snapshots on the player's machine. Whether this fits the
  Steam Subscriber Agreement is the owner's call. The fallback is subscribing
  through Steam (`steam://url/CommunityFilePage/<id>`).
- SteamCMD `workshop_download_item 730 <id>` should also work (not tested).

### Dependencies of an old BSP

An old BSP can reference materials and models that later builds removed or
changed. My VPK comparison (§2) shows only 221 files removed and 678 changed
between the Aug 2018 VPK and the 2023 VPK, so 2018-era maps should mostly
resolve against the Legacy VPK. Pre-2016 classics (old Nuke, old Inferno) may
miss more. Workshop BSPs often embed missing content in their pakfile lump
(**unverified per map**).

Review on 2026-10-11 downloaded all 14 entries in `workshop::OLD_MAPS` and
verified their pinned archive sizes and SHA-1s. Every BSP pakfile includes
navigation under the original map name (`maps/<base>.nav`); renamed archive
files must resolve metadata there, without borrowing a newer install's NAV.
The first asset probe found missing dependencies in four maps. See
[OLD-MAPS.md](../OLD-MAPS.md) for final checks and remaining work.

## 2. Old game builds (Steam depots)

- **Depot layout (local, verified):** `appmanifest_4465480.acf` (CS:GO Legacy)
  installs depots **731** (content, manifest 1224088799001669801), **732**
  (Windows binaries, 6314304446937576250), 735, 736, 737, 738: the same depot
  IDs CS:GO used under 730. On this machine app 730 now uses CS2 depots
  2347770/2347771/2347774, and its 731-738 entries are 8-byte stubs.
- **Manifest history:** SteamDB lists manifests per depot at
  https://steamdb.info/depot/731/manifests/ and
  https://steamdb.info/depot/732/manifests/ (you must log in to see more than
  the latest 10). Builds by date: https://steamdb.info/app/730/patchnotes/ .
  Target builds, with dates from
  [GameTracking-CSGO](https://github.com/SteamDatabase/GameTracking-CSGO)
  commits:
  - 1.36.4.5: 2018-08-02/03 (Panorama default, Horizon Case). Commit `093b49738d`.
  - 1.36.4.6 to 1.36.4.9: Aug 7 to 17, 2018 (MP5-SD added Aug 15). The last
    build with Scaleform: 1.36.4.9 / 1.36.5.0, Aug 17 to 21.
  - 1.36.5.1: 2018-08-29/30 (Scaleform removed). Commit `bac0a02a41`.
  - Danger Zone / free-to-play: 2018-12-06 (1.36.7.x, **unverified exact
    version**).
  - I found no publicly quoted manifest IDs for these builds. Get them from
    SteamDB while logged in.
- **Can an owner still download them? Unverified, and doubtful.** Steam
  requires a "manifest request code" for every manifest download
  ([SteamDB blog](https://steamdb.info/blog/manifest-request-codes/)).
  Developers can block old manifests. Since January 2025, Steam often
  refuses codes for anything but the current manifest
  ([DepotDownloader #594](https://github.com/SteamRE/DepotDownloader/issues/594),
  where xPaw says it is a Steam-side change;
  [#614](https://github.com/SteamRE/DepotDownloader/issues/614)). A May 2026
  report says old manifests still work on the *default* branch only
  ([#714](https://github.com/SteamRE/DepotDownloader/issues/714)). For CS:GO,
  people trying depot 732 after CS2 reported 401 errors
  ([Steam thread](https://steamcommunity.com/app/730/discussions/0/604146344638092524)).
  Because Legacy re-hosts depots 731/732 under app 4465480, an owner could try
  `download_depot 4465480 731 <manifest>` in the Steam console
  (`steam://open/console`), or DepotDownloader with their own login
  (`-app 4465480 -depot 731 -manifest <id>`), as well as the same with app
  730. **Test this once with the owner's account before planning around
  it.**
- **Valve DMCA precedent (important):** on 2018-06-22 Valve had the Panorama
  layouts and JavaScript (decrypted from `code.pbin`) removed from
  GameTracking-CSGO
  ([commit 4f61aa4a68](https://github.com/SteamDatabase/GameTracking-CSGO/commit/4f61aa4a68),
  notice in `csgo/panorama/README.md`). Never commit Panorama XML, CSS or JS,
  even small excerpts. Read them at runtime only.
- **What an old build would add over Legacy:** I compared the Aug 2018 VPK
  file list (GameTracking `csgo/pak01_dir.txt` at 1.36.5.1, with CRCs)
  against the local 2023 VPK. Of 79,478 files in 2018, **only 678 changed and
  221 were removed**. The 2023 VPK has 54,419 extra files.
  - Sounds: 9,914 sound files in 2018. Only **27 changed**: MAG-7 pump,
    SCAR-20 bolt, player death 1-6, breathe, wade, geiger, sparks/zaps,
    `ui/panorama/bg_nuke_01`, `gameover_newskillgroup_01`. 5 Hydra campaign
    voice files were removed. **Every gun's firing sound is byte-identical**
    (e.g. `weapons/ak47/ak47-1.wav` CRC e0fb8223 in both). The weapon
    soundscript `scripts/game_sounds_weapons.txt` differs only in the
    **HE grenade explosion** (2018: `explode3-5.wav`; 2023:
    `hegrenade_detonate_02/03`, new distant set), a few draw/volume and
    channel tweaks, and new snowball/healthshot entries.
  - Scaleform case sounds (`ui/csgo_ui_crate_open`, `csgo_ui_crate_item_scroll`,
    `csgo_ui_crate_display`, `item_reveal*`), menu sounds (`menu_accept`,
    `csgo_ui_button_rollover_large`, ...) and the default menu music
    (`music/valve_csgo_01/mainmenu.mp3`) are all **identical**.
  - Weapon models changed: first-person models for Deagle, AWP, AUG, SG 553,
    P250, Tec-9, Nova, Sawed-Off, MAC-10, MP7, UMP-45, G3SG1, SSG 08, Negev,
    CZ75 (`pist_223`), Healthshot, plus most glove and sleeve arms. World
    models for Deagle, MAC-10, UMP-45, G3SG1, CZ75, C4, defuser, armour.
    Default player models: 57 files in `models/player/custom_player` changed.
  - Panorama images: 53 changed (mostly tournament logos and map
    screenshots for Dust II, Cache, Vertigo, Militia). 73 removed (country
    flags, `gungamebomb.svg`). `resource/flash/images` (Scaleform): 72
    removed.
  - Panorama layouts/CSS/JS live in `panorama/code.pbin`. In 2023 it is a
    `PAN\x02` header plus a signature, followed by a normal ZIP (726 files:
    302 XML, 213 CSS, 207 JS). Python `zipfile` opens it. A 2018 build would
    carry the Aug 2018 Panorama in the same container, and the 2018 menu
    videos in `panorama/videos/`.
  - Maps are loose BSPs in `csgo/maps/` and not tracked in the VPK listing.
    The Workshop snapshots (§1) cover them.

Conclusion: for the Scaleform target, **an old depot is not needed** for UI
art, menu sounds, case sounds, music or gun sounds. It would only restore the
few changed weapon and player models, the HE explosion sound, and 2018
Panorama.

## 3. What changed between 2018 and 2023

Dates come from official notes where linked. Otherwise they are
**unverified**.

UI:
- 2018-06-20: Panorama beta, opt-in
  ([Valve](https://blog.counter-strike.net/2018/06/20482/),
  [PC Gamer](https://pcgamer.com/csgos-new-panorama-ui-is-now-live)).
- 2018-08-01/02: Panorama default. Horizon Case. Scaleform still available
  through a launch option.
- 2018-08-15: MP5-SD added
  ([Dexerto](https://www.dexerto.com/csgo/fan-favorite-smg-has-finally-been-added-to-csgo-141010)).
- 2018-08-29: Scaleform removed (see §0).
- 2018-12-06: Danger Zone and free-to-play. New main-menu backgrounds
  (Blacksite, Sirocco). The Legacy install has `blacksite*.webm`,
  `sirocco*.webm` and `dz_*_preview.webm`.
- 2019-11-18: Operation Shattered Web. Agents, and an agent model on the main
  menu (unverified exact date).
- 2020-12-03: Broken Fang. 2021-09-21: Riptide (operation menus,
  `op_riptide_*` videos in the install). 2020-06: main-menu background chooser
  (`ui_mainmenu_bkgnd_movie`; `promoted_settings.js` advertises it for June
  11-30 2020). Final choices in the Legacy `client.dll`: ancient, anubis,
  blacksite, cbble, nuke, sirocco_night, vertigo.
- Panorama case opening (2023 Legacy, from the shipped
  `popup_capability_decodable.js`; facts only, do not copy code): reel of
  **38 tiles**, the winner placed near the end. It scrolls with a 3-second
  smooth scroll and stops at a random 10-90% offset inside the winning tile.
  42 tick sounds are scheduled from 0.000 s to 5.004 s, spacing out from
  ~63 ms to ~620 ms. The item is revealed at **6 s**. Whether the 2018 Panorama
  version used the same numbers is unverified. **The Scaleform reel in the
  reference is a different, smaller widget.** Measure it from footage (§4),
  or by running `inventorypanel.swf` (see Recommended pipeline).

Sounds: see §2. The big rifle sound overhauls happened before 2018 (e.g. the
sniper rework of Sept 2016:
[escene.de](https://www.escene.de/csgo-update-bringt-neuen-sound-fur-die-awp/);
rifles: [GosuGamers](https://www.gosugamers.net/counterstrike/news/41534-cs-go-update-brings-sounds-accuracy-changes)).
Between Aug 2018 and Oct 2023, Valve changed no gun firing sound.

Maps in the 2018 pool, and what makes the 2023 Legacy copy differ:
- Dust II: reworked 2017-10-10. Updated again before 2019-06, 2020-01 and
  2021-09 (snapshot dates).
- Inferno: reworked 2016-10. Updated before 2020-04, 2020-12 and 2021-09.
- Nuke: reworked 2016-02-17. Updated 2018-02, then before 2019-10, plus later
  changes (no later snapshot found; **unverified**).
- Train: reworked 2016-12. Updated before 2020-06. Left the pool 2021-05 for
  Ancient
  ([VDC CS2 maps](https://developer.valvesoftware.com/wiki/Counter-Strike_2/Maps)).
- Cache: left the pool 2019-10. The 2023 Legacy `de_cache.bsp` is probably
  the later FMPONE rework (**unverified**). Use the 1.37.1.9 snapshot.
- Mirage, Overpass, Cobblestone: several post-2018 updates (snapshots
  above). Cobblestone left the pool 2019-03.
- Vertigo: reworked 2019-03 (snapshot 1885079840 is the new version). The old
  version is 1193870504.

## Recommended pipeline

Everything is read on the player's machine. Nothing is committed or
published. Ordered by friction, lowest first.

1. **Menu, case opening, UI sounds, music, gun sounds: read the Legacy
   install. Nothing extra needed.**
   - Art: `resource/flash/*.swf` (Scaleform movies), `resource/flash/images`
     and `materials/panorama/images/*` from the VPK, plus `csgo_default.vtf`.
     Fonts come from `fontlib*.swf` (Scaleform) or `panorama/fonts/*.vfont`.
     Strings come from `resource/csgo_*.txt` (`SFUI_*` tokens).
   - Two ways to render it. (a) **Spike first:** run Valve's SWFs through
     Ruffle (MIT/Apache, Rust/wgpu) inside the Bevy app. Stub the Scaleform
     game API that the ActionScript calls, and feed our local
     profile/friends/inventory data. If it works, this is pixel-exact by
     construction. Feasibility is unverified: CS:GO used Scaleform-only
     extensions. (b) **Fallback:** a native Bevy layout measured against the
     references. Pull vector shapes and bitmaps out of the SWFs at runtime
     with the `swf` crate, so no art is redrawn or committed.
   - Sounds: `scripts/game_sounds_ui.txt` (`UI.CrateOpen`,
     `UI.CrateItemScroll`, `UI.CrateDisplay`, `item_reveal*`), menu sounds,
     and `music/valve_csgo_01`. All are byte-identical to 2018. Gun sounds
     from the Legacy VPK are the 2018 sounds. To match 2018 exactly, play the
     HE grenade with the old `explode3-5.wav` entries (still in the VPK) and
     keep the 2018 soundscript parameters as *data we observed*, not copied
     files.
2. **2018 maps: Valve's compatibility versions, fetched automatically.** On
   first run (or when a server picks a map), the launcher looks up the item
   in a small built-in table (`map -> workshop id`, the §1 table; IDs are
   facts, not assets). It calls the keyless `GetPublishedFileDetails`,
   downloads `file_url` from Valve's CDN into the user's data folder,
   unzips the `.bsp`, and mounts it ahead of the Legacy maps. Also scan
   `steamapps\workshop\content\730\*\*_legacy.bin` in every Steam library, so
   players who subscribed through Steam need no download. Offer an "Open in
   Steam" subscribe link as the fully Steam-sanctioned alternative. The
   owner should decide whether the direct CDN fetch is acceptable.
3. **Optional, for completionists: a 2018 build from Steam depots.** Only if
   a one-time test with the owner's account shows
   `download_depot 4465480 731 <manifest>` (or app 730) still works for a
   1.36.4.x manifest. If it does, the launcher can detect a second install
   folder (any directory with `steam.inf` `PatchVersion=1.36.*`) and overlay
   it. That adds 2018 Panorama (`code.pbin`, read at runtime only, never
   committed: see the 2018 DMCA), the six 2018 menu movies, the original
   weapon and player models, and the old HE sound. Getting the manifest ID
   and running the console command are manual steps, so this stays an
   advanced option, not a requirement.
4. **Timing and animation not in any file** (Scaleform reel speed, easing,
   tile count): measure frame by frame from the §4 videos, or observe
   `inventorypanel.swf` running in Ruffle. Record the numbers in
   `docs/`, never the code.
5. **Fingerprint inputs:** log `steam.inf` `PatchVersion` and the depot 731
   manifest from `appmanifest_4465480.acf` (currently 1224088799001669801), so
   bug reports say which content set was loaded.
