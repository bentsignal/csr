# Scoped recoil metadata

The installed Legacy schema retains alternate recoil declarations that the
rewrite already preserves but did not select when scoped. For example, AUG
normal/alternate magnitude is 24/16, SG553 28/19, AWP 78/25 and SSG08 33/25.
These are facts from the installed 2023 schema, SHA1
`c1361d351802b7be5f55245c331f5f1d6b36ad35`, not a 2015 balance profile.

Scoped pattern generation now selects finite alternate angle, angle variance,
magnitude and magnitude variance values, using each normal field if its
alternate declaration is missing or invalid. The normal-only observation table
and motion response are not admitted for a scoped mode. Scope/unscoped changes
invalidate derived patterns and discard an unsupported normal-mode response;
changing between two zoom levels does not. Recoil index and attack deadlines
remain intact. Existing burst and suppressor transitions retain their paths.
The catalog interpretation digest distinguishes peers using this selection;
raw item-schema identity and serialized weapon fields remain unchanged.

One World/TickInput witness warms an unscoped-only observation, scopes through
ordinary secondary input and fires a real shot. It compares the alternate
zero-recoil control with an ordinary unscoped shot, while checking retained
spray index, primary deadline and ammo consumption. It is an internal metadata
selection regression, not a native scoped recoil law or a claim about the
fallback procedural generator's exact fidelity. Local compilation is pending
coordinated verification. No scoped cadence change accompanies this fix:
which inherited cycle declarations native weapons actually select remains a
separate observation question.
